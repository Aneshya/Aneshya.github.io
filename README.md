## 🚀 Features

- ✨ Modern, responsive UI with smooth animations  
- ⌨️ Typewriter effect for dynamic role display  
- 🌌 Subtle animated & glowing background effects  
- 🧭 Active navigation highlighting based on scroll  
- 🎯 Section reveal animations on scroll  
- 🧊 Glassmorphism project and achievement cards  
- 🧠 Skills section with real technology logos  
- 📱 Fully responsive (desktop & mobile)
